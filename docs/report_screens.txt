В данном разделе представлены основные экраны реализованного приложения.

Каталог товаров. Страница каталога отображает товары выбранной категории в виде карточек с фотографией, названием и ценой. Слева расположена панель фильтров, различающаяся для разных разделов: для мотоциклов - категория, бренд и год выпуска; для экипировки, запчастей и аксессуаров - тип; для остальных - бренд. Над списком - строка поиска и выбор сортировки по цене, снизу - постраничная навигация. Переключение между разделами (мотоциклы, экипировка, масла, шины, запчасти, аксессуары) выполняется через вкладки в шапке.
[Рисунок X - Страница каталога товаров]

Карточка товара. На странице товара отображаются галерея изображений, описание, цена и информация о наличии. Для мотоциклов дополнительно выводится таблица технических характеристик (год выпуска, объём двигателя, мощность, масса, цвет). Кнопка «В корзину» добавляет товар без перезагрузки страницы - счётчик в шапке обновляется асинхронно через HTMX.
[Рисунок X - Карточка товара]

Корзина и оформление заказа. Корзина доступна по значку в шапке и показывает список добавленных позиций с миниатюрами, ценой, количеством и итоговой суммой. Количество можно изменить или удалить позицию прямо в таблице. Форма оформления заказа содержит поля контактных данных и адреса доставки; при наличии авторизации они предзаполняются из профиля. После успешного оформления отображается страница подтверждения заказа.
[Рисунок X - Страница корзины]

Регистрация и авторизация. Формы входа и регистрации выполнены в едином стиле с остальными страницами. При регистрации пользователь вводит email и пароль, затем на отдельной странице - шестизначный код подтверждения, присланный на почту. На странице входа предусмотрено сообщение об успешной активации и ссылки для перехода между формами входа и регистрации.
[Рисунок X - Страница регистрации]

Личный кабинет. На странице личного кабинета сверху расположена форма редактирования контактных данных (ФИО, телефон, адрес), ниже - список заказов пользователя с датой, составом и статусом каждого заказа.
[Рисунок X - Личный кабинет]

Панель администратора. Для управления контентом используется встроенная административная панель Django с русифицированными заголовками разделов и собственными настройками отображения (превью изображений, встроенные формы для галереи товара, фильтры по колонкам). Через неё администратор управляет каталогом товаров, справочниками, заказами, отзывами, партнёрами и пользователями.
[Рисунок X - Панель администратора]
